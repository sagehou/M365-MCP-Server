# M365 MCP Server v0.1.8

## 文件夹查询与按名称移动

- Python 服务器、Windows .NET 和 Windows Go 同步增加只读 `mail_list_folders`，
  使用相同的可选参数 `parent_folder_id`、`next_link`，不新增依赖或权限范围。
- 使用 `{}` 查询顶层。每次只返回一层，`folders` 最多包含 100 个可见文件夹，包含
  `id`、`displayName`、`parentFolderId`、`childFolderCount`、`totalItemCount`、
  `unreadItemCount`，不递归展开整棵树，也不包含隐藏文件夹。
- 将返回的文件夹 ID 作为 `parent_folder_id` 查看其直接子文件夹。返回 `next_link`
  时保持相同父级继续查询，直到 `next_link` 为 null。顶层分页继续省略父级或传空字符串。
  中文、引号和同名文件夹均保留。
- 例如“把邮件移动到 项目/发票”，Agent 先查询相关层级和分页，匹配名称及父级，明确
  同名目标，再把选定的文件夹 ID 传给现有 `mail_move`。显示名称不是目标 ID。
  `mail_move` 保留原有参数和已知文件夹支持；移动后使用返回的新 `message_id`。
- 调用者和 Graph 返回的续页链接均校验同一文件夹列表路径及受限分页参数，沿用登录用户
  的 `/me` 客户端重建请求，不直接访问任意 URL。兼容 ID 的等价编码和不透明分页游标。
  .NET 路径校验改为单独处理查询部分，避免将有效游标中的 `..` 当成路径穿越。
- 文件夹名称附带不可信内容标记。异常 Graph 集合或续页链接返回错误，不会当成空列表或
  已完成结果。文件夹分页不代表 `mail_search` 已支持续页。

```json
{}
```

```json
{"parent_folder_id": "<返回的父文件夹 ID>"}
```

```json
{"parent_folder_id": "<相同的父文件夹 ID>", "next_link": "<返回的 next_link>"}
```

明确目标后调用 `mail_move`：

```json
{"message_id": "<邮件 ID>", "destination_folder_id": "<选定的文件夹 ID>"}
```

## 面向 Agent 的 Windows 一键安装

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/sagehou/M365-MCP-Server/v0.1.8/scripts/install-windows-local.ps1')))
```

- 安装脚本默认 Go，自动选择最新稳定版 AMD64/ARM64 包，校验安装包、包内 EXE 和
  完整 Skill 压缩包的 SHA-256，安装到 `%LOCALAPPDATA%\Programs\M365-MCP`。
  支持 Windows PowerShell 5.1 和 PowerShell 7，无需管理员权限或 Go 运行时。
- 交互安装询问自建应用 Client ID 和租户 ID。留空使用共用的内置公开 Client ID 和
  `organizations`；自建单租户应用填写所属目录 GUID。无需输入 Client Secret 或
  令牌；通过系统浏览器登录，并遵循目标租户的同意策略。
- Agent 可先取得用户选择，再传 `-NonInteractive -ClientId '<应用程序客户端GUID>'
  -TenantId '<目录租户GUID>'`。`-SkipLogin` 推迟浏览器登录，`login-command.txt`
  保存准确命令；`-InstallDirectory` 可指定其他绝对安装目录。
- 脚本生成包含 stdio 条目的 `mcp.json`，安装双语指南及完整 `m365-mail/` 文件夹，
  保留公开客户端登录流程。将生成的 `m365-local` 条目合并到客户端原有 MCP 配置，
  按客户端的 Skill 机制安装 Skill，再刷新连接。脚本不改写客户端专用配置，选择
  `-SkipLogin` 时不会悄悄登录。重复安装前先关闭本地 MCP 进程；仍可手动安装 .NET 或 Go。

## 升级与版本能力

1. 部署 v0.1.8 容器或替换 .NET/Go EXE，更新完整 `m365-mail` Skill 文件夹，再刷新或
   重启 MCP 连接。已有有效的本机加密登录状态继续可用；这些功能无需重新配置应用、租户
   或 Graph 权限。
2. 通用 Skill 新增移动前匹配文件夹名称和层级、继续文件夹分页、保留同名候选的流程。
   以当前暴露的工具和 Schema 为准；仅更新 Skill 无法给旧服务器或 EXE 增加文件夹查询。
   中英文指南、工具契约、安装说明和能力数量已对齐。

| 能力 | Python 服务器版 | Windows .NET | Windows Go |
| --- | --- | --- | --- |
| 邮件工具 | 12 项；开启服务器管理的 OAuth 后为 14 项 | 13 项 | 14 项 |
| `mail_list_folders` | 只读；一次一层一页 | 相同接口 | 相同接口 |
| 传输 | 带认证的 HTTPS Streamable HTTP | stdio | stdio；带认证的本机回环 HTTP |
| 直接保存原文件 | 不提供 | 流式保存；默认上限 150 MiB 且可配置 | 与 .NET 的接口和行为一致 |
| 文本提取 | PDF、DOCX、XLSX、PPTX、TXT、Markdown | UTF-8 文本、CSV、JSON、XML | PDF、DOCX、XLSX、PPTX、TXT、Markdown |
| 下载 URL | 服务器管理的 OAuth；HTTPS | 不提供 | 本机单次使用 HTTP URL |

原文件保存继续默认使用 Windows 下载目录下的 M365-MCP，支持每次调用的
`download_dir` 覆盖、`M365_MAX_DOWNLOAD_MIB` 配置及不覆盖已有文件。文本读取和 Go
临时下载 URL 仍限制 10 MiB。草稿附件仍限制 20 MiB，沿用现有文件类型规则。发送仍需
逐封批准或有边界的自动化授权。本次未升级或新增依赖。
