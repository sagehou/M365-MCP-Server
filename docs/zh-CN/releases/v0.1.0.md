# M365 MCP Server v0.1.0

首个稳定版本是一个面向 WorkBuddy 兼容客户端和其他 Streamable HTTP MCP Client
的自托管 Outlook Mail MCP Gateway。它有意保持较小的工具面，并将 Microsoft
Graph 访问限制在当前登录用户的委托 `/me` 邮箱内。

## 包含能力

- Microsoft Entra Bearer Token 校验、Tenant Allowlist 和 Required Scope 约束。
- 通过 On-Behalf-Of（OBO）访问 Microsoft Graph 委托权限。
- OAuth Protected Resource 与 Authorization Server Discovery。
- 可选的 Dynamic Public-client Registration、带 S256 PKCE 的 Interactive
  Authorization Code Flow、加密持久 Session、Refresh-token Rotation、Replay
  Rejection 和重启恢复。
- 每个请求独立的用户身份隔离和安全结构化 Audit Event。
- WorkBuddy Connector Package 及三个限定范围的 Skill。
- 使用 Non-root Runtime 与 Health Check 的 Docker / Docker Compose 部署。

## Outlook Mail 工具

- `mail_search`
- `mail_get`
- `mail_list_attachments`
- `mail_read_attachment`
- `mail_download_attachment`
- `mail_mark_read`
- `mail_archive`
- `mail_move`
- `mail_set_category`

附件提取支持 PDF、DOCX、XLSX、PPTX、文本和受保护的压缩包检查。Parser Process
具有 Byte、Archive Expansion、Resource、Timeout 和 Cancellation 限制。下载
Ticket 为短时且只能使用一次。

## Container Image

Release Workflow 会把同一个已经通过 Smoke Test 的 Linux x64 Image 发布为：

- `ghcr.io/sagehou/m365-mcp-server:v0.1.0`
- `ghcr.io/sagehou/m365-mcp-server:0.1.0`
- `ghcr.io/sagehou/m365-mcp-server:0.1`
- `ghcr.io/sagehou/m365-mcp-server:latest`

```bash
docker pull ghcr.io/sagehou/m365-mcp-server:v0.1.0
```

本版本支持 `linux/amd64`，不声明提供 ARM64 Image。

## 发布门禁

创建 `v0.1.0` Tag 前，维护者必须完成并记录
[发布检查清单](../release-checklist.md)，包括真实 WorkBuddy 登录与 Refresh、重启
恢复、双用户隔离、跨租户隔离以及代表性真实邮箱附件测试。Mock CI Coverage 不能
替代这些证据。

Tag Workflow 会验证 Tag 与 `project.version` 一致、提交属于经过 Review 的
`main` 历史、存在双语 Release Notes，并依次通过完整 Python Test、Production
Image Build、精确 Image Smoke Test 和 Compose 校验；之后推送所有 Image Tag，
最后才创建 GitHub Release。

## 已知限制

- Search 只返回一个有边界的 Page 和 `next_link` Hint；尚未实现 Opaque
  Continuation Cursor。
- 尚未包含 Folder Discovery、Draft、Reply、Forward、Send、Shared Mailbox、
  OCR、RBAC、Rate Limiting 和 Observability。
- 尚未包含 Calendar、OneDrive、SharePoint 和 Teams。
- OAuth 仍需显式配置；具体部署在完成自己的真实 Client 验收前不应启用。
- 不支持 Multi-replica；临时 Download Ticket 和 SQLite OAuth 状态假设只有一个
  Server Instance。
- Windows 本地 stdio 单文件 Runtime 仍在开发，不属于 v0.1.0。

部署前请阅读[部署清单](../deployment.md)、[WorkBuddy OAuth 指南](../workbuddy-oauth.md)
和[实现复核状态](../review-status.md)。
