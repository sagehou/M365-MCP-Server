# M365 MCP Server v0.1.2

本版保留原有 NativeAOT 程序，增加 Windows 本机单用户 Go 版，升级依赖，并为
三个 Windows EXE 补齐资源管理器“详细信息”中的版本资源。

## Windows 文件详细信息

| 字段 | 内容 |
| --- | --- |
| 产品名称 | M365 MCP Server |
| 产品版本 | 0.1.2 |
| 文件版本 | 0.1.2.0 |
| 公司 | sagehou |
| 版权 | Copyright (c) 2026 sagehou |
| 文件说明 | M365 MCP Server (Windows Local)，或 Windows Local Go |

同时填写原始文件名、内部名称、备注和资源语言。Go 版在 AMD64、ARM64 链接前嵌入
资源，CI 在 Windows 读取实际 PE 资源，字段缺失或版本不一致就会失败。
命令行和 MCP 返回的版本同步为 0.1.2。

## 发布文件

- `m365-mcp-windows-local-amd64.exe`：保留的 .NET 10 NativeAOT 版，附
  `m365-mcp-windows-local-amd64.exe.sha256`。
- `m365-mcp-windows-local-go-amd64.exe`、
  `m365-mcp-windows-local-go-arm64.exe`：Go 单文件程序，各附 `.exe.sha256` 文件。
- 对应的 Go ZIP 包：EXE、中英文指南、MIT 许可和第三方许可。
  `SHA256SUMS.txt` 校验三个 Windows EXE 与两个 Go ZIP。
- `LICENSE`：项目 MIT 许可。三个 EXE 均生成 GitHub Artifact Attestation。

Release 流水线同时将通过测试的 Linux x64 镜像发布为
`ghcr.io/sagehou/m365-mcp-server:v0.1.2`、`:0.1.2`、`:0.1` 和 `:latest`。

## Go 版

Go 主机支持公共客户端浏览器登录、当前用户 DPAPI 存储、stdio 或本机鉴权 HTTP，
提供 12 项邮件工具，包括创建/发送草稿、受目录限制的本地草稿附件、独立进程中的
PDF/Office 文本提取，以及短时一次性附件下载。NativeAOT 版继续提供文件选择器、
Ephemeral Mode 和远程附件推送辅助程序。

两套程序的命令和配置统一见[本地版指南（.NET 与 Go）](https://github.com/sagehou/M365-MCP-Server/blob/main/docs/zh-CN/windows-local.md)。
Python 依赖通过 `uv.lock` 锁定；Windows 和容器的构建、测试均只在 GitHub Actions 执行。

---

EXE 尚无 Authenticode 签名；补充详细信息不保证减少杀软误报。MD5 和 SHA-1 仅供旧式
杀软白名单表单使用；请用 SHA-256 与 GitHub Artifact Attestation 核验来源。EXE 变化
后须重新审核白名单。
AMD64 在 Windows 执行运行检查，ARM64 进行交叉编译和版本资源检查。真实 Entra/客户端
兼容性及 ARM64 运行仍需在目标电脑验收。更新日期：2026-11-11。
