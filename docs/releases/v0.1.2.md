# M365 MCP Server v0.1.2

This release adds the Windows single-user Go edition alongside the existing
NativeAOT edition, updates dependencies, and fills the Windows Explorer file
details for all three executable assets.

## Windows file details

| Field | Value |
| --- | --- |
| Product name | M365 MCP Server |
| Product version | 0.1.2 |
| File version | 0.1.2.0 |
| Company | sagehou |
| Copyright | Copyright (c) 2026 sagehou |
| File description | M365 MCP Server (Windows Local), or Windows Local Go |

Original filename, internal name, comments, and resource language are included.
Go resources are embedded before linking for both AMD64 and ARM64. CI reads
the resulting PE resources on Windows and rejects missing or incorrect fields.
CLI and MCP versions are updated to 0.1.2 as well.

## Release assets

- `m365-mcp-windows-local-amd64.exe`: the retained .NET 10 NativeAOT edition, with
  `m365-mcp-windows-local-amd64.exe.sha256`.
- `m365-mcp-windows-local-go-amd64.exe` and
  `m365-mcp-windows-local-go-arm64.exe`: standalone Go executables, each with
  its own `.exe.sha256` file.
- Corresponding Go ZIP packages: executable, English/Chinese guides, MIT
  license, and third-party notices. `SHA256SUMS.txt` covers all three Windows
  EXEs and both Go ZIPs.
- `LICENSE`: project MIT license. GitHub Artifact Attestation covers all three
  release executables.

The release workflow also publishes the tested Linux x64 container as
`ghcr.io/sagehou/m365-mcp-server:v0.1.2`, `:0.1.2`, `:0.1`, and `:latest`.

## Go edition

The Go host supports public-client browser sign-in, current-user DPAPI storage,
stdio or authenticated loopback HTTP, and twelve mail tools. It includes draft
creation/sending, root-confined local draft attachments, isolated PDF/Office
text extraction, and short-lived single-use attachment downloads. The
NativeAOT edition retains its file picker, ephemeral mode, and remote push helper.

See the [local guide (.NET and Go)](https://github.com/sagehou/M365-MCP-Server/blob/main/docs/windows-local.md)
for each edition's commands and configuration. Python dependencies are locked
with `uv.lock`; Windows and container builds/tests run only in GitHub Actions.

---

The executables remain unsigned; version details do not add an Authenticode
signature or guarantee fewer antivirus detections. MD5 and SHA-1 support legacy
antivirus allowlist forms; verify SHA-256 and GitHub Artifact Attestation for
provenance. Updated executables need new allowlist reviews. AMD64 receives a Windows
runtime smoke test; ARM64 is cross-compiled and its version resources are
checked. Live Entra/client compatibility and ARM64 runtime acceptance require
the target PC. Updated: 2026-11-11.
