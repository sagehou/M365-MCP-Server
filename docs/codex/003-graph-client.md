# Task 003 - Microsoft Graph Client

## Goal

Implement the Microsoft Graph integration layer.

## Requirements

- Create a reusable Graph client abstraction.
- Use delegated tokens acquired through OBO.
- Support Microsoft Graph retry handling.
- Handle throttling responses.
- Keep Graph operations isolated from MCP tools.

## Deliverables

- Graph client wrapper
- Mail service foundation
- Error handling
- Unit tests

## Non goals

- No MCP tool exposure.
- No document extraction.
